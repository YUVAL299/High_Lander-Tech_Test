# High Lander – Navigation Game

A web-based navigation game: the player walks (for real, or simulated) to a goal
placed near them, following the shortest walkable route drawn on an OpenStreetMap
map. The route updates as the player moves.

## Quick start

```bash
docker compose up --build
```

Then open <http://localhost:8080>.
